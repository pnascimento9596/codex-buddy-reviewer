# v0.5.0-rc.3 release note

## Decision

Publish the privacy, lifecycle, governance, evaluation, and checked-JavaScript hardening accumulated after rc.2 as a third release candidate, exclusively through the protected public-source workflow. The candidate is not stable and does not claim native host acceptance or live Windows provider readiness.

## Reviewed defects and fixes

The bounded Phase 2 review used OpenAI Codex `gpt-5.6-sol` and Ollama Cloud `glm-5.2:cloud` against hash-pinned exact-source packets. Every accepted claim was reproduced locally before implementation. The GLM route twice described itself as a Claude model; invocation metadata remains the authoritative attribution and those verdicts are weighted accordingly.

The reproduced defects were silent private turn-snapshot cleanup failure, cleanup-warning loss during adopted and replayed continuations, unsafe orphan pruning when a turn-session inventory is unreadable, and publication-guardrail gaps for receipt-shaped non-JSON or singly encoded JSON-string state. rc.3 surfaces bounded cleanup status through each lifecycle path, preserves ambiguous claimed receipts, and rejects the reviewed accidental receipt shapes. Multi-layer encoding, compression, base64, and splitting remain explicit scanner non-goals; Buddy's product boundary remains that runtime receipts are written only below private state.

PRs #17 and #19 prevent clean-filter execution during evidence capture and distinguish provable stage-0 filtered bytes from unproven filtered working-tree content. PR #21 rejects non-owner release dispatches before validation, protected-environment approval, or release concurrency. PR #23 adds mutation-controlled deleted-file, truncation/abstention, and control-character grounding cases. PR #24 adds exact-version strict checked JavaScript for the five authorized review-boundary modules without changing emitted runtime JavaScript or the focused 112-test behavioral result.

## Deliberate limitations

- The Phase 2 provider-call ceiling was exhausted before the final scanner and lifecycle follow-up fixes; those fixes ship with reproduced failing regressions converted to passing tests, not an invented provider re-review.
- RC publication does not prove native pet rendering, host transcript continuation display, native hook trust, five-pet host observation, or live Windows provider egress.
- Windows reviewer contact remains fail closed pending current-user-only DACL implementation and real platform evidence.
- The published-artifact POSIX trial is a post-publication Phase 6 gate and remains distinct from source-checkout validation.
