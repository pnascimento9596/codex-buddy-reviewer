## Hook timeouts

`hooks/hooks.json` configures `UserPromptSubmit` **210** s and `Stop` **1890** s
above product capture (180 s) and default provider (1800 s) ceilings. Host
enforcement of those values on Codex CLI 0.146.0 is **UNVERIFIED** without a
host session observation (SessionEnd clamp to 3 s is known; Stop/UserPromptSubmit
clamps were not evidenced in the installed binary strings). See CHANGELOG.

## Protected publication gate

- [ ] The candidate PR passes the complete local chain, secret scan, skill/plugin validators, publication boundary, and exact-head protected CI.
- [ ] The candidate is squash-merged normally and protected-main CI passes at the exact merge head.
- [ ] Dispatch attribution follows `docs/releases/dispatch-attribution.md` two-phase protocol (no self-referential future SHA); historical VALIDATION.md rc.4 text stays frozen.
- [ ] `.github/workflows/release.yml` is dispatched from unchanged protected `main` with `version: 0.5.0-rc.5` and `publish: true` only under separate owner instruction.
- [ ] The workflow rebuilds and re-verifies the positive artifact, deterministic archive, parentless distribution commit, annotated tag, checksums, and attestations before publication.
- [ ] Independent post-publication verification proves anonymous accessibility, tag/commit/tree identity, asset/sidecar/GitHub digests, and expected workflow attestation identity.

The protected workflow, not this checklist, performs publication. No manual source tag is created, moved, or deleted. **This lane stops at the candidate head; it does not dispatch.**
