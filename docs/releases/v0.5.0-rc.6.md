## Operator-facing purge note

On marketplace installs, automatic-review runtime state can live under
`~/.codex/plugins/data/<plugin-identity>/` while older CLI paths used
`~/.codex/codex-buddy-reviewer/`. rc.5 `data purge` could report success while
receipts remained under the plugins/data root. rc.6 purge enumerates every
buddy-owned runtime root. **Operators who purged under rc.5 should purge once
more after upgrading** (automatic mode disabled).
