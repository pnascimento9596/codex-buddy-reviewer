## Security boundary

Windows x64 egress is not enabled by platform name alone. The exact packaged helper hash and protocol, architecture, ACL-capable filesystem, current live root/ancestor set, and disengaged emergency kill switch must all verify. Failures stop before provider contact or settle as definite non-execution/platform-integrity containment according to the lifecycle boundary. There is no silent provider/model substitution or direct-process fallback.

The DACL claim protects against other local non-admin users and inherited wide ACLs on supported Windows filesystems. It does not claim protection against Administrators, SYSTEM, or a malicious same-user process. Windows ARM64 remains fail-closed until separately reviewed helper bytes ship.
